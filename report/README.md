# Báo cáo Bài tập 2 – Game đua xe thi đấu đối kháng online

- `LTM_Nhom_GameDuaXe_Java.docx` – báo cáo nộp (kiến trúc, thiết kế chung, 4 phần cá nhân).
- `img/` – 7 hình vẽ dùng trong báo cáo.
- `draw.py` – sinh lại hình vẽ (matplotlib, font Segoe UI).
- `build_docx.py` – dựng lại file docx (python-docx) từ hình trong `img/`.

Sinh lại: `python draw.py && python build_docx.py`
